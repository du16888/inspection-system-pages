# 第三方项目检查系统 · 原型

物管小区品质服务第三方检查系统的前端原型。

## 在线预览

- 入口: https://du16888.github.io/inspection-system-pages/
- 管理后台: https://du16888.github.io/inspection-system-pages/inspection-admin.html
- 移动端: https://du16888.github.io/inspection-system-pages/inspection-mobile.html

## 简介

- 4 套检查标准:金百合 / 向日葵 / 郁金香 / 紫荆花
- 400 个物管项目,每套标准 68 项检查指标
- 5 大模块:环境卫生 30% · 安全管理 15% · 设施设备 20% · 绿化养护 15% · 客户服务 20%
- 总分 = Σ(各模块得分率 × 权重) × 100

## 角色

- 总部品质人员:管理后台派发任务、审核结果
- 第三方检查员:移动端现场打分、上传照片
- 项目经理:移动端签字确认或退回复审
